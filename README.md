# 🎙️ VOXControl

### AI-Powered Voice Assistant

[![Python](https://img.shields.io/badge/Python-3.x-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://www.python.org/)
[![Vosk](https://img.shields.io/badge/Vosk-Speech%20Recognition-00A67E?style=for-the-badge)](https://alphacephei.com/vosk/)
[![Google Gemini](https://img.shields.io/badge/Google%20Gemini-AI-4285F4?style=for-the-badge&logo=google&logoColor=white)](https://ai.google.dev/)

> **VOXControl** is a Python-based voice assistant that combines speech recognition, generative AI, text-to-speech, web automation, and system controls into an interactive desktop application.

---

## Features

-  **Voice Recognition** — Converts spoken commands into text using Vosk.
- **AI Assistant** — Uses Google Gemini to answer natural-language questions.
- **Text-to-Speech** — Responds to users through voice using pyttsx3.
- **Web Automation** — Opens websites and web applications through voice commands.
- **System Control** — Supports commands such as restart, sleep, and hibernate.
- **IP Information** — Retrieves public IP and location-related information.
- **Interactive GUI** — Desktop interface built with Tkinter with an animated voice visualization.
-  **Multithreaded Processing** — Keeps voice recognition and the interface responsive.

##  How It Works

```text
User Voice

    ↓

    ↓
┌──────────────┬──────────────┬──────────────┐
│ System Tasks │ Web Actions  │ Gemini AI    │
└──────────────┴──────────────┴──────────────┘
                       ↓

                 Voice Response
```

##  Installation

### 1. Clone the Repository

```bash
git clone https://github.com/myahyashk/VOXControl.git
cd VOXControl
```

### 2. Install Dependencies

```bash
pip install vosk pyaudio pyttsx3 requests numpy matplotlib google-generativeai retrying
```

### 3. Configure Vosk

Download a suitable Vosk speech-recognition model and update its path in the Python file.

```python
model_path = "path/to/vosk-model"
```

### 4. Configure Gemini

Set your Gemini API key as an environment variable instead of placing it directly in the source code.

```text
GEMINI_API_KEY=your_api_key
```

### 5. Run

```bash
python "joyo adalynnvw2.py"
```
